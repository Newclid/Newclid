Frontend
========

The Newclid frontend is an interactive geometry canvas built with vanilla TypeScript and Vite — no UI framework.
It lets users sketch geometric constructions, submit them to the Newclid prover backend, and explore the returned proofs with a step-by-step visualisation overlay.

The sections below cover everything a new developer needs to get up and running, understand the design, and make changes confidently.
